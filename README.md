# Dream Stalker — Dreamcore Site

Landing page untuk mod Fabric Dream Stalker by kuru studio.

## Verified mod details

- Fabric mod, target Minecraft 1.21.8, Java 21
- Stalker entity, fear meter 0–100, creep/jumpscare feedback
- Dreamspaces: Mossy Rooms, Motel Treats, Lone Theatre
- Commands: `/stalker summon`, `/stalker fear <0-100>`, `/stalker dream <map>`, `/stalker shift`
- Download: `downloads/dreamstalker-1.0.0.jar`

## Audio

Place a licensed/permitted MP3 at `assets/dreamcore.mp3` to enable the looping player. The provided YouTube URL is shown as source context only; the site does not rehost it without a permitted audio file.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.
